## 项目

### 水镜

以水、场景与牌阵构成的中文互动体验。“水镜不答来日。只鉴影，不断语。”

入口：`shuijing/index.html`

### Shopping Together｜购物同行

以“不替你决定，只陪你多看一眼”为核心的陪伴式购物原型。项目使用本地规则与浏览器存储完成交互，不接入 API，也不上传用户记录。

入口：`shoppingtogether/index.html`

## 本地运行

可以直接打开各项目目录中的 `index.html`。如需模拟线上静态托管环境，可在仓库根目录启动本地服务器：

```powershell
python -m http.server 4173
```

随后访问：

- `http://127.0.0.1:4173/shuijing/`
- `http://127.0.0.1:4173/shoppingtogether/`

## 浏览器兼容性

建议使用 Chrome、Edge、Safari 或较新版本的系统浏览器。部分旧内核浏览器可能无法完整呈现背景与装饰效果。
